# v0.13 — 集中が合流するレイド

目的：自分の集中した時間が仲間の集中時間に重なり、同じボスを倒すことが伝わる体験。

## 実装済みの範囲

- Home：火口背景、大きなヴォルガ、共有HP、みんなの累計・参加人数、自分の受理済み時間、今回届ける時間。
- ABYSS + RAGの集中画面：キャンプ→稜線→火口の静止背景。既存タイマーの進捗を使用。本文をスクロール可能にし、停止・再開・終了操作を下部に固定。
- 帰還：仲間の青緑の光→自分の金色の光→紹介した仲間の分数＋自分の分数。この場の合計と世界全体の累計は区別。
- ヴォルガ3状態と既存アイテム3種を新しい透過素材に。既存ID・報酬確率は維持。
- テーマを夜の紺色、青緑、金色へ更新。既存アトラスも保持。

## 整合性

- LIVEかつ有効な世代があるときだけ共有人数・分数を表示。プレビューとオフラインを明示。
- 自分の共有分数は同じ世代のACCEPTED/ALREADY_COUNTEDのみ。セッションIDの重複を除外。
- 終了演出は受理後のサーバーHPを再取得してから行う。反映済みの再現であり、演出操作で再送しない。最終HPは取得したHPに一致。
- 仲間の実データは同じレイド世代の最大2件。別世代や世代不明の貢献を混ぜない。
- Homeの最近の貢献も同じ世代のみ。レイド世代の更新時に再取得する。
- 同時参加の着弾順は復元できないため、自分が最後の一撃だったとは断定しない。
- 仲間の最近の貢献が空でも、世界で自分が最初だったとは断定しない。
- DEBUG + LOCAL_PREVIEWだけにサンプル演出。オフラインに架空の仲間を補わない。
- 通信待ち・失敗は既存の結果・再送導線に戻る。FIRST 25専用演出は維持。

## 素材

組み込み先：`app/src/main/res/drawable-nodpi/*_v13.png`、9点。
生成モードは組み込みImageGen。モデル指定がないため、ImageGen2.5使用済みとは扱わない。
プロンプト仕様・サイズ・透過・SHA-256は `v013-art-manifest.json`。
